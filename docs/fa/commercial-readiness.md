# آمادگی تجاری و شروط انتشار

[English](../en/commercial-readiness.md) · [Deutsch](../de/commercial-readiness.md).

نسخهٔ ۰٫۱٫۰ یک پیش‌نمایش مهندسی قابل‌اجرا و پایهٔ محصول است. به‌عنوان سامانهٔ سازگار با همهٔ مقصدها، دارای گواهی Production، آزمون نفوذ، HA یا آمادهٔ فروش و استقرار نامحدود معرفی نمی‌شود. وجود سورس و تست محلی به‌تنهایی این ویژگی‌ها را اثبات نمی‌کند.

موارد تحویل‌شده شامل سرور Java، رابط سه‌زبانه، نسخه‌بندی، پارامتر اعلانی، کانکتور CRUD/Query/Service، کلید Scopeدار، URL/OpenAPI، Retry محافظه‌کارانه، Idempotency و صف پایدار، رمزنگاری، متادیتای Audit، آزمون، نمونه و فایل استقرار است. زیرمجموعهٔ تأییدشده جدا ثبت شده و Benchmark یا نشان CI ساختگی وجود ندارد.

| حوزه | شرط پیش از مشتری | وضعیت |
|---|---|---|
| سازگاری | آزمون زندهٔ هر محصول/نسخه/قرارداد | عمدتاً باز |
| هویت | OIDC/SSO و گردش کلید اولیه | پیاده نشده |
| وضعیت و HA | دیتابیس متادیتا، Migration، Claim توزیع‌شده | فایل تک‌گره |
| اتصال | Pool، Rotation، Timeout درایور | اتصال در هر عملیات |
| شبکه | Egress، TLS و مرز DNS Rebinding | بررسی بهره‌بردار |
| کیفیت | Browser/CSP بومی، Windows/Container، بار و دسترس‌پذیری | بخشی باز |
| امنیت | Pentest مستقل، SBOM، پاسخ به آسیب‌پذیری | تکمیل نشده |
| عملیات | Restore، Retention، پایش و پشتیبانی | پایه موجود |
| انطباق | بررسی قرارداد، حریم خصوصی و حقوقی | بدون گواهی |
| محصول | Upgrade، Onboarding، تعهد پشتیبانی و فروش | تکمیل نشده |

Pilot باید ماتریس باریکی مثل یک نسخهٔ PostgreSQL و یک قرارداد REST داشته باشد، نه وعدهٔ همهٔ سیستم‌ها. حساسیت داده، حداکثر بار، مدیریت خطا و مسئول تطبیق را روشن کنید. آزمون تخریبی فقط روی زیرساخت دورریختنی باشد.

اول مقصدهای واقعی را بپذیرید، مشکلات شدید امنیت را ببندید و Restore/تطبیق را ثابت کنید. سپس وضعیت، هویت و Lifecycle اتصال را ارتقا دهید. SOAP کامل یا پروتکل Camel با تست مستقل اضافه شود. صورتحساب، Marketplace و چندمنطقه‌ای کار آیندهٔ محصول هستند، نه قابلیت پنهان فعلی.

پیش از GitHub، انتخاب مجوز MIT را تأیید و Secret، دادهٔ مشتری، کاتالوگ، JAR و کد اختصاصی را حذف کنید. اسکریپت، تصویر و گزارش را بررسی، Workflow را فعال و Digestهای بررسی‌شده را ثابت کنید. کانال خصوصی گزارش امنیت ایجاد و امتحان کنید. مخزن GitHub ساخته نشده، Push انجام نشده و Release راه دور منتشر نشده است. مصاحبه، درآمد، فروش یا موفقیت Production تضمین نمی‌شود.
