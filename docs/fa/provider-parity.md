# تطبیق مفاهیم پروایدر GraphBPMS و محدودهٔ مستقل

[English](../en/provider-parity.md) · [Deutsch](../de/provider-parity.md).

پروژه، الگوی پروایدر اتصال را مستقل پیاده می‌کند. کد GraphBPMS، Schema اختصاصی و دادهٔ مشتری کپی نشده و سازگاری جایگزینی مستقیم ادعا نشده است.

| مفهوم | Connector Hub | مرز |
|---|---|---|
| پروایدر | پیش‌نویس نسخه‌دار | Schema و API متفاوت |
| تنظیمات دیتابیس/سرویس | اتصال مستأجر و Secret | نیازمند Driver و Allowlist |
| Normal | INPUT | فقط نام تعریف‌شده |
| Constant | CONSTANT | سمت سرور |
| Systemic | SYSTEM | tenant، principal، correlationId، now |
| تنظیمات سیستم | CONFIG | مقادیر مستأجر |
| پیکربندی محرمانه | SECRET | مرجع Secret اتصال |
| Query | JDBC QUERY/EXECUTE | مقدار Bind و SQL مورداعتماد |
| پروسیجر/تابع | PROCEDURE/FUNCTION | IN/OUT/INOUT، بررسی فروشنده |
| REST/WSDL | خانوادهٔ HTTP و بازرسی WSDL | بدون Binding عمومی |
| FieldsRoot | JSON Pointer | پیش از Mapping |
| فیلد خروجی | outputMappings | Pointer نسبی و نوع |
| صفحه/فیلتر/ترتیب | پوشش page | زیرمجموعهٔ وابسته به کانکتور |
| مصرف پروایدر | POST نسخه‌دار | Scope و Snapshot |
| Async | Job پایدار | یک Worker، نه Bus توزیع‌شده |

فراخواننده شیء `input` می‌فرستد، نه لیست اصلی Name/FieldType/Value. ثابت، سیستم، تنظیمات و Secret را نمی‌تواند Override کند. پروایدر اجازهٔ خواندن فایل دلخواه پیکربندی سرور ندارد. JSON Pointer زبان اجرای آزاد JavaScript یا عبارت دلخواه نیست. `${name}` کامل نوع را حفظ می‌کند و درون متن رشته می‌سازد؛ SQL از `:name` استفاده می‌کند.

تولید CRUD محافظه‌کارانه است: یک کلید اصلی تأییدشده، شناسهٔ بررسی‌شده و نسخهٔ اختیاری. OptionalItems، AdvancedEditor، SystemEntity، فرم/گزارش پویا و دسته‌های اختصاصی شبیه‌سازی نشده‌اند. `absoluteMethodHelper.runProvider` وجود ندارد؛ برنامهٔ مصرف‌کننده می‌تواند HTTP منتشرشده را از سرور خودش فراخوانی کند.

اجرای C#/Java/Script دلخواه از رابط، Binding امنیتی WCF، Service Bus اختصاصی GraphBPMS، Submit فرم، متغیر نمونهٔ فرایند، گزارش‌ساز، مجوز سلسله‌مراتبی Entity و مهاجرت خودکار کاتالوگ پیاده نشده‌اند. این محدودیت مانع تبدیل انعطاف‌پذیری ظاهری به Remote Code Execution می‌شود. افزونهٔ Java بررسی‌شده فقط زمان شروع نصب می‌شود.

برای مهاجرت، مقصد، مجوز، منبع پارامتر، Null، Timeout، خروجی و مصرف‌کننده را فهرست کنید. یک پروایدر را با دادهٔ ساختگی بازسازی کنید، موفقیت/خطا/تکرار را در مقصد جدا بسنجید، خروجی و Paging را مقایسه و مصرف‌کنندگان را مرحله‌ای منتقل کنید. Import بدون بررسی به معنای برابری رفتار نیست. تشابه اصلی در روند اتصال، پارامتر، اجرا، نگاشت و انتشار است، نه برابری همهٔ امکانات یک BPMS بالغ.
